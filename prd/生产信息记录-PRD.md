# 生产信息记录 PRD

## 1. 背景

扫码上料每次「发送」产生一条生产流水。本期先落「生产信息查询」页面（查询 + 导出），记录写入接口（K3）随表结构一并提供，供扫码上料模块后续接入。原始需求见 `生产信息记录.md`。

## 2. 用户与场景

- S1 质检/工艺员按投料时间区间导出某天台账，Excel 交车间存档。
- S2 收到客户投诉批次 B20261001-3，在页面输入批号（无需区分左右）定位到该吊架投料记录，追溯投料/进线/出线时间。
- S3 交接班时按吊架号查该吊架当日全部投料记录。
- S4 车间大屏按默认列表查看当前"正在加工"的批次（出线时间为空的行）。

## 3. 功能总览

| # | 模块 | 功能描述 |
|---|---|---|
| F1 | 记录列表 | 独立菜单"生产信息记录"。分页表格，列依次为：流水号、作业员、吊架号、投料槽位、投料时间、进线时间、出线时间、批号(左)、料号(左)、规格(左)、阻值(左)、精度(左)、数量(左)、批号(右)、料号(右)、规格(右)、阻值(右)、精度(右)、数量(右)、状态。默认投料时间倒序。 |
| F2 | 条件查询 | 投料时间区间（按投料时间筛选）、批号（左或右任一命中即返回）、吊架号（精确）。条件间为"与"，可重置。 |
| F3 | 状态标识 | 出线时间为空 →「正在加工」；非空 →「已完成」。页面只读展示，不落库。 |
| F4 | 导出 Excel | 按当前查询条件导出（无条件=全部），列头、顺序、内容与列表完全一致；文件名 `生产记录_导出时刻.xlsx`。 |
| F5 | 记录写入接口 | POST /api/prod-records（K3）：扫码上料「发送」时调用，服务端生成流水号与投料时间。本期无页面入口。 |

## 5. 字段说明（列表/导出同序）

| 字段 | 说明 |
|---|---|
| 流水号 | 系统生成：`PR + yyyyMMdd + 4位流水`，全局唯一 |
| 作业员 | 扫码上料时录入的操作员姓名（本期无登录，文本） |
| 吊架号 | 投料吊架编号 |
| 投料槽位 | 投料上料发生的槽位名称 |
| 投料时间 | 记录生成时间（发送时刻） |
| 进线时间 | 批次进线时刻，可空 |
| 出线时间 | 批次出线时刻，可空；空=正在加工 |
| 批号/料号/规格/阻值/精度/数量 (左) | 左侧批次信息 |
| 批号/料号/规格/阻值/精度/数量 (右) | 右侧批次信息 |
| 状态 | 出线时间空=正在加工；否则已完成 |

## 6. 业务规则

| # | 规则 |
|---|---|
| R1 | 记录由上料发送动作自动生成（K3），本页面只读，无修改/删除入口。 |
| R2 | 时间区间查询以投料时间为准，非进线/出线时间。 |
| R3 | 批号查询匹配左右任一批号（包含匹配）；吊架号为精确匹配。 |
| R4 | 导出与列表同一查询条件、同一排序，保证所见即所得；导出不受分页影响。 |
| R5 | 流水号服务端生成、全局唯一；重试 3 次仍冲突按 50000 处理。 |
| R6 | 本期不提供编辑/删除接口；进线/出线时间的更新接口随扫码上料模块提供。 |

## 7. 验收标准

1. 默认进入页面按投料时间倒序展示全部记录，分页正常。
2. 三个条件可单独或组合使用，重置后恢复全量。
3. 批号条件命中左批号或右批号的记录均返回。
4. 出线时间为空的记录状态显示「正在加工」，非空显示「已完成」。
5. 导出的 Excel 列头、顺序、数据与页面当前筛选结果一致（不受分页影响）。
6. K3 新增记录流水号自动生成且唯一，投料时间取服务端当前时间。
